# Sharan — Through My Lens

A free, GitHub Pages-ready photography portfolio.

## Publish it for free with GitHub Pages

1. Create a free account at GitHub if you don't already have one.
2. Create a **New repository**. A simple name is `sharan-photography`.
3. Upload **all files and folders inside this ZIP** (especially `index.html`, `style.css`, `script.js`, and the `photos` folder).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a public `github.io` link.

No paid hosting is required.

## Notes

- The portfolio includes all 32 photographs supplied in the original ZIP.
- Image filenames were cleaned only for easier web hosting; the original filenames are preserved in the source ZIP.
- The site is responsive and includes category filters and a full-screen photo viewer.
